# 变更：从专属站点壳升级为通用 URL EXE 打包器

## 目标

将当前仅封装“AI漫剧创作”的项目改造为可复用的线上 URL 打包工具。每个打包任务必须提供 URL、产品标题和图标；默认生成 Windows x64 安装包，并可选择生成 x86（32 位）安装包。

## 目标用户流程

1. 填写 HTTPS URL、产品标题与产品图标。
2. 选择目标架构：默认 x64，可选 x86。
3. 由云端 Windows Runner 生成对应的 NSIS 安装包。
4. 下载安装包及 SHA-256 校验文件。

## 范围

- 提供严格的打包配置格式与示例配置。
- 将当前站点信息降级为示例，而非硬编码产品定义。
- 将 GitHub Actions 改为按打包配置与目标架构构建。
- 规划本地表单、图标文件校验和云端任务提交接口。

## 非目标

- 不绕过网站访问控制、版权限制或登录限制。
- 不将私密图标或 URL 自动上传到公开仓库。
- 首期不实现无需授权的公共云端打包服务；触发私有 GitHub Actions 需要仓库写入权限或受控服务端。

## 验收标准

- 同一模板可由不同配置生成不同产品标题、URL、图标和稳定 identifier 的 EXE。
- 未提供 URL、标题或图标时不允许提交构建。
- x64 为默认目标；x86 构建使用独立的 32 位 Rust 目标与输出目录。
- 每个云端构建产物包含安装包和 SHA-256 校验文件。
